# Contributing to AgentShield AI

Thank you for your interest in contributing to **AgentShield AI**, an open-source, automated security & adversarial vulnerability scanner for AI agents and LLM applications.

## Development Workflow

1. Fork and clone the repository.
2. Install dependencies: `npm install`
3. Set up environment variables: `cp .env.example .env`
4. Run tests: `npm test`
5. Run development server: `npm run dev`

## Code Standards
- Strict TypeScript (`strict: true`).
- Modular services and dependency injection.
- Security-first handling of all test inputs and tokens.
- All new features must include automated test coverage.
