## Quickstart

```bash
# Clone the repository
git clone git@github.com:rajeshwari229080/Datheon_AI_Startup_-_SaaS_Launch_Lab.git
cd Datheon_AI_Startup_-_SaaS_Launch_Lab

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Run automated tests
npm test

# Launch development server
npm run dev
```

Visit `http://localhost:3000` to preview the waitlist landing page and `http://localhost:3000/app.html` for the active MVP dashboard.
